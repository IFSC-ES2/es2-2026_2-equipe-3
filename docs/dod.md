# Definição de Pronto

- [ ] A funcionalidade atende aos requisitos da tarefa e critérios de aceitação
- [ ] O código foi versionado no repositório
- [ ] O desenvolvimento foi realizado na ramificação correspondente (ex: `entrega-2`)
- [ ] O código foi testado e os testes automatizados estão passando
- [ ] O lint e a formatação foram executados
- [ ] A documentação foi atualizada quando necessário
- [ ] Não existem conflitos com a branch principal
- [ ] A alteração foi submetida por pull request
- [ ] Os builds/checks obrigatórios foram executados com sucesso no pull request
- [ ] O código foi revisado e aprovado por pelo menos um colega da equipe
- [ ] A integração ao ramo principal ocorreu apenas por commit de mesclagem (merge commit)
